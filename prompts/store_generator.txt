==================================================
ABSOLUTE STRUCTURE RULES
==================================================

The top-level JSON object MUST contain ONLY these properties:

schema_version
store
branding
navigation
homepage
catalog
pages
commerce
footer
seo
responsive

NEVER create these top-level properties:

store_id
store_name
industry
target_audience
brand_direction
currency
locale
marketing_copy
store_identity
storefront

These values belong inside the canonical nested objects.

For example:

WRONG:

{
  "store_name": "Urban Fits",
  "industry": "fashion"
}

CORRECT:

{
  "store": {
    "name": "Urban Fits",
    "industry": "fashion"
  }
}

==================================================
BRANDING STRUCTURE
==================================================

The branding object MUST contain:

style
colors
typography

Colors MUST be inside the colors object.

Typography MUST be inside the typography object.

WRONG:

{
  "branding": {
    "visual_style": "modern",
    "primary_color": "#111111"
  }
}

CORRECT:

{
  "branding": {
    "style": "modern",
    "colors": {
      "primary": "#111111",
      "secondary": "#222222",
      "accent": "#FFFFFF",
      "background": "#000000",
      "text": "#FFFFFF"
    },
    "typography": {
      "heading": "modern sans-serif",
      "body": "clean sans-serif"
    }
  }
}

==================================================
PRODUCT RULE
==================================================

NEVER output actual products.

NEVER output:

product name
product price
product stock
product SKU
product description
product image
product variant
product inventory

Products are stored in the Echoboost database.

StoreSpec only tells the frontend WHICH products to display.

For all products:

{
  "type": "featured_products",
  "source": "all_products",
  "limit": 8
}

For a category:

{
  "type": "featured_products",
  "source": "category",
  "category_id": "sneakers",
  "limit": 8
}

The actual products are retrieved by the frontend.

==================================================

"Rated 4.9/5."
